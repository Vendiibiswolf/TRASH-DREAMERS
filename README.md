REQUIREMENTS

Codename Engine

Windows (tested platform: Windows)

INSTALLATION

Download and extract the TRASH DREAMERS archive.

Locate your Codename Engine installation folder.

Open the mods folder.

Place the TRASH DREAMERS folder inside mods.

Launch Codename Engine.

Enable TRASH DREAMERS in the mod selection menu, if necessary.
